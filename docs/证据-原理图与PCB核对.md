# 证据：从工程文件里抠出来的网表与铜箔

所有数字都不是"看图说话"，而是从 `hardware/backups/功率计算器总_2026-10-19-20-33.epro2`
里的明文 `.epru` 解析出来的。原始输出在 `data/` 下，可用 `tools/eprj_tool.py` 复现。

## 0. 文件格式说明（为什么走备份而不是 .eprj2）

| 文件 | 本质 | 能不能读连接性 |
|---|---|---|
| `功率计算器总.eprj2` | SQLite，文档正文 `dataStr` 是加密的 | ❌ 只能看表结构和文档树 |
| `backups/*.epro2` | **zip**，里面有 `IMAGE/`、`project2.json`、`功率计算器总.epru` | ✅ `.epru` 是逐行明文 JSON |

`.epru` 每行形如 `{"type":"LINE",...}||{...}`，按行首 `DOCHEAD` 分组，就能拿到
`SYMBOL`（符号）、`FOOTPRINT`（封装）、`SCH_PAGE`（原理图页）、`PCB`（板）四类文档的全部对象。

## 1. 原理图解析：坐标变换怎么校准的

- 符号引脚坐标是符号自身的坐标系，实例只给了 `(x, y, rotation)`，**没有给旋转方向**；
- 先用 33 个单脚电源符号（GND/VCC）*证明* 平移是 `abs = comp + pin`（33/33 命中导线端点）；
- 再用 2 脚元件（电阻/电容）在 rot=90/180/270 下的命中率，选出旋转公式
  `q = {0:(px,py), 90:(py,-px), 180:(-px,-py), 270:(-py,px)}`（顺时针，无镜像），
  三档全部 100% 命中（23/23、25/25、35/35）。

命中判据很硬：**引脚端点必须与导线端点坐标完全相等**（坐标是整数网格，不存在容差问题）。

[VCC]  (22): …; U2.3(3); U4.VDD(40); …（含 LGS5145 输出的 15uH）
[GND]  (37): …; U2.4(4); U4.VSS(41); …
[(unnamed)] (2): 470nF.2; U4.VCORE(32)          ← VCORE 只接一颗 470nF，正确
[(unnamed)] (4): H3.1; H3.2; H3.3; LGS5145.FB(3) ← ⚠ 反馈脚只连跳线三个短接脚

`H3` 三个脚之间确实有导线（带两个结点）把它们短接，并用一段竖线接到 `FB`——所以原理图上
**反馈脚没有接到任何一组分压中点**，分压中点只到 `H4` 的三个脚（`FB1/FB2/FB3` 三个 netport 就在 H4 旁边）。

## 3. PCB 解析

| 项 | 数量 |
|---|---|
| 元件 | 28 |
| 走线（LINE） | 352 段 |
| 过孔（VIA） | 54 |
| 铺铜定义（POUR） | 11 块（`IN+`/`SW`/`VCC`/`IN-`/`GND`），但**填充数据 `pourFill` 为空** |

焊盘位置 = `footprint.pad.centerX/centerY` 经实例 `angle` 旋转后平移到 `component.x/y`；
网络判定用"**走线端点/过孔中心与焊盘中心坐标重合**"（`data/pcb_copper_report.txt` 里有每个焊盘的判定结果）。

### 3.1 调试口四根线

| 焊盘 | 坐标（单位 0.0254mm） | 判定到网络 | 备注 |
|---|---|---|---|
| U2.1 | (570, -350) | SWDIO | 精确落在铜箔端点 |
| U2.2 | (670, -350) | SWCLK | 精确落在铜箔端点 |
| U2.3 | (770, -350) | VCC | 精确落在铜箔端点 |
| U2.4 | (870, -350) | **无走线** | 最近铜箔：IN+ 64 单位(≈1.6mm)、VCC 70 单位；**最近的 GND 铜箔在 287 单位(≈7.3mm) 外** |

→ U2.4 只能靠铺铜连地。既然实物实测共地正常，说明供货板子铺了铜；但**原理图/PCB 里没有为它画线**，
属于隐患（改版/重铺铜时容易掉）。

### 3.2 MCU 侧

| pad | 坐标 | 网络 |
|---|---|---|
| 12 (PA19/SWDIO) | (546.1, -711.6) | SWDIO |
| 13 (PA20/SWCLK) | (546.1, -731.2) | SWCLK |
| 32 (VCORE) | (918.2, -867.1) | `$1N199` = 只有 `470NF.2` |
| 38 (NRST) | (994.0, -691.9) | NRST |
| 40 (VDD) | (994.0, -652.5) | VCC |
| 41 (VSS) | (994.0, -632.8) | GND |

**NRST 网络上只有两个焊盘**：`U8.38` 和 `10NF.2`（另一侧 `10NF.1 = GND`）。
原理图里的 4.7kΩ 上拉、SW7 复位键、H2 排针**在 PCB 上都不存在**。

### 3.3 3.3V 反馈

| 焊盘 | 网络 |
|---|---|
| LGS1.3（FB） | `FB3` |
| 13K1.2 | `FB3` |
| 3K1.2 | `FB3` |
| 13K1.1 | VCC |
| 3K1.1 | 无走线（应为 GND） |

即 **VCC —13.1kΩ— FB —3.1kΩ— GND**，分压比 5.23×。
原理图另一套可选分压是 `100k/32k`(4.13×)、`82.5k/16k`(6.16×)、`13k/4.3k`(4.02×)，
若 LGS5145 的 FB 基准是 0.8V，则 4.13× → 3.30V（对），而 PCB 的 5.23× → **≈4.18V**（超 MSPM0 3.6V 上限）。
**这一条必须实测 VCC 才能定论**（基准若是 0.6V 则 PCB 是 ≈3.14V，属正常）。
