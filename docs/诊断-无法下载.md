> 现象：`JLink - Cortex-M Error / No Cortex-M SW Device Found`
> 你已确认：**GND 共地正常**；**只接 VCC+GND 时 LED 亮**（= 3.3V 轨有电）

## 结论变了：**SWD 走线本身是对的，问题不在“没布线”上**

我把最新备份重新解包比对（和 10-13 那份相比只少了 R7 旁边那颗 7K，其他一样）：

| 检查项 | 最新 PCB 实测结果 |
|---|---|
| U2.1(SWDIO) → U8 pad12 (PA19/SWDIO) | ✅ 走线端到端精确落在焊盘中心 |
| U2.2(SWCLK) → U8 pad13 (PA20/SWCLK) | ✅ 同上 |
| U2.3 → VCC | ✅ |
| U2.4 → GND | 文件里没有走线，**只有靠铺铜**；你实测共地 OK → 说明生产出来的板子铺铜把它连上了，这条排除 |
| U8.40 = VCC / U8.41 = GND / U8.32 = VCORE+470nF | ✅ 都对 |
| MCU 型号引脚对应 | ✅ TI 手册确认 pin12 = PA19/SWDIO、pin13 = PA20/SWCLK，符号库没错 |

**所以：板子的 SWD 硬件通路是通的。报了 `No Cortex-M SW Device Found` 说明 SW-DP 完全没应答，剩下这 5 个原因，按可能性排：**

---

## ① 供电没问题 ≠ 芯片活着（最容易被误导的一点）

LED 是接在 **VCC 轨**上的（VCC → LED → 1K → GND），**它亮只证明 3.3V 有电，跟 MCU 死没死没关系**。

**判定芯片是否活着，只需量一个点：`VCORE`（U8 第 32 脚，或那颗 470nF 电容的靠芯片侧）**
- 正常：**≈1.2~1.4V 稳定**（芯片内部核心 LDO 在工作）
- 0V：芯片没上电/没焊好/已经废了 → 不用再折腾 J-Link 了

## ② 复位脚 NRST：这颗板子上**只有一颗 10nF 电容，没有上拉、没有复位键**

- 原理图里 NRST 有 `4.7k 上拉 + 10nF + 复位键 SW7 + H2 排针`；
- 但**PCB 上这些全都没放**，铜箔上 NRST 只连了 `U8.38` 和 `10nF` 到地，别的什么都没有。
- 如果 MSPM0 的 NRST 内部上拉不足 / 电容漏电 / 焊接残留助焊剂漏电，NRST 会一直偏低 → **MCU 一直处于复位 → LED 照亮、SWD 完全没反应**，症状完全对得上。

**测：NRST 直流电压应 ≈3.3V（>2.5V）。若 <1V → 飞一颗 10kΩ 从 NRST 拉到 3.3V 立刻见效。**

## ③ 调试排针脚序不是通用 SWD 线序（最容易插错）

| 本板 U2 | 网络 | 通用 4P SWD 线（ST-Link / J-Link 4P / 多数国产仿真器） |
|---|---|---|
| 1 | **SWDIO** | 1 = 3V3 |
| 2 | **SWCLK** | 2 = SWDIO |
| 3 | **VCC** | 3 = SWCLK |
| 4 | **GND** | 4 = GND |

按 1:1 直插的后果：3V3→SWDIO、SWDIO→SWCLK、SWCLK→VCC、GND→GND —— **地是对的、电也有（LED 会亮！），但 SWDIO/SWCLK 全错** → 完全一样报 `No Cortex-M SW Device Found`。
> 这和你现在的现象（LED 亮、共地 OK、就是读不到）**高度吻合**，优先查这条。

**5 秒确认**：万用表蜂鸣档
- `U2-1 ↔ U8 pad12` 应 ≈0Ω
- `U2-2 ↔ U8 pad13` 应 ≈0Ω
- 若量出来是 `U2-1 ↔ U8 pad13`，就是交叉了。

## ④ 3.3V 实际电压（分压可能是错的）

- 原理图 3.3V 那档是 `100k / 32k` = 4.13 倍
- **PCB 上实际是 `13K1 / 3K1` = 5.23 倍**
- LGS5145 的 FB 基准若是 0.8V → 输出 **≈4.18V**（超 MSPM0 的 3.6V 上限，芯片可能已经打伤）；若是 0.6V → ≈3.14V（能用）

**测：USB-C 上电时量 VCC。** 3.1~3.35V 正常；**4.1~4.3V 就是分压错了**，MCU 大概率已过压损坏，改分压（按 0.8V 基准 3.3V 应约 `13.1k / 4.3k`）并换芯片。
> 调试期间建议**只让仿真器供 3.3V，不要同时插 USB-C**，避免两路打架。

## ⑤ 工具链

- 本机装了 **J-Link V9.28**（`C:\Program Files\SEGGER\JLink_V928`），但 Keil 目录里是 **7.96h** 的老 `JLinkARM.dll`（`D:\keil\ARM\Segger`）→ MSPM0G3507 支持不全，Keil 里要换成 V9.28 的 DLL。
- 器件必须选 **MSPM0G3507**（不是 STM32 / 不是通用 Cortex-M0）。
- 用 **Connect under reset**，速度先降到 **1000 kHz**。
- 命令行直接验（能区分“没地/没电”和“芯片死”）：
  ```
  "C:\Program Files\SEGGER\JLink_V928\JLink.exe" -device MSPM0G3507 -if SWD -speed 1000 -autoconnect 1
  ```
  先看 `VTref` 是否 ≈3.3V，再看 `IDCODE` 是否读得到。

## 这块板需要改的三处（下一版）

1. **U2 第 4 脚补 GND 走线**（现在只靠铺铜，DRC 也查不出来，容易在改版时丢）。
2. **NRST 补 10k 上拉 + 复位按键**（原理图有，PCB 漏了）。
3. **统一 3.3V 分压**：原理图 `100k/32k` 与 PCB `13.1k/3.1k` 不一致；顺便把 H3/H4 那套选择跳线接对——原理图里 `FB` 只连到 H3 的三个**短接在一起**的脚，三个分压中点只到 H4，反馈环是开的（这块是原理图层面真错，你以后改一版会被带坑）。
